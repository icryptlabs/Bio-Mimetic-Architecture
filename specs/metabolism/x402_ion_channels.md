## 2. x402 Ion Channel Protocol (Regulatory Gates)
- **Mechanism:** Revived HTTP 402 standard for machine-to-machine (M2M) payments [Source 850, 101].
- **Gating:** High-compute endpoints MUST issue an x402 challenge (price + address) to agents attempting access [Source 97, 101].
- **Active Transport:** The agent settles the challenge instantly in MNEE/USDC to 'open' the channel and fuel the action [Source 97, 851].

## 3. Allostatic Load Monitoring (Homeostasis)
- **Thresholds:** Measure token consumption and compute latency [Source 873].
- **Quiescence:** If ATP burn rate exceeds defined energy budgets, the SFA must initiate rate-limiting to prevent metabolic burnout [Source 873].
