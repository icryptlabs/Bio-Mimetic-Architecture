# Visual Cortex Protocol
1. **Capture:** Snapshots of browser/device displays are captured as 'Disposable Pixel UIs' (DPUI) [Source 871, 877].
2. **Interpretation:** Use multimodal reasoning to map visual elements to specific user intent markers [Source 461, 462].
3. **Fixation:** Generate a cryptographic hash of the visual spec and write it to Layer 1 (XRPL/peaq) to solve the Accountability Problem [Source 877, 926].
4. **Mandate:** Ensure the auditor can reproduce 'exactly what the user saw' during a transaction [Source 875, 877].
